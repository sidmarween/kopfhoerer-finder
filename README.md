# 🎧 Kopfhörer-Finder

Android-App, um verlorene Bluetooth-Kopfhörer wiederzufinden.

- Sucht gleichzeitig per Bluetooth Low Energy und klassischem Bluetooth
- Gekoppelte Kopfhörer stehen immer oben in der Liste
- „Heiß / kalt“-Anzeige mit großem Kreis, Prozent, Trend (näher / weiter) und grober Entfernung
- Piepton und Vibration werden schneller, je näher du kommst
- Suchton und Piepen wahlweise nur links, nur rechts oder auf beiden Hörern
- Spielt einen lauten Suchton direkt auf dem Kopfhörer ab, sobald er verbunden ist

Download: **Releases** → neueste Version → `KopfhoererFinder.apk`
